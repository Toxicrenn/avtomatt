# avtomatt

Учебный репозиторий с практическими заданиями по автоматизации тестирования (курс SkyPro).

## Ключевые проекты

- **урок/h** — тестирование связки API + БД: класс-обёртка над REST API и класс-обёртка над PostgreSQL (SQLAlchemy), тесты сверяют данные из API с данными в базе.
- **lesson_07** — UI-автотесты калькулятора на Selenium с Page Object Model и отчётами Allure.
- **lesson_04** — параметризованные тесты на pytest с разделением на позитивные и негативные сценарии.

## Стек

Python, pytest, Selenium, requests, SQLAlchemy, Allure

## Остальное

Папки lesson_01-03, 05, 06, 08, 09 — практика по темам курса (ООП, работа со строками, API, UI).
